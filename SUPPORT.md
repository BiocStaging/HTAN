# Getting help

**Questions about using the package** ("how do I find all Level 4 scRNA-seq
files for one atlas?") are best asked on the
[Bioconductor support site](https://support.bioconductor.org/) with the tag
**`htan`**. Answers there are searchable and reach a wider audience than this
repository.

**Questions about HTAN data** (what a field means, why a file seems missing,
how an assay level is defined) can go to the support site too, or to the
[*Data question*](https://github.com/seandavi/HTAN/issues/new?template=data_question.yml)
issue form here. Questions about the HTAN portal, data submission or
controlled access (dbGaP phs002371) belong with the
[HTAN Data Coordinating Center](https://humantumoratlas.org).

**Bugs and feature requests** go to the
[issue tracker](https://github.com/seandavi/HTAN/issues). For a bug, include
a minimal reproducible example, `sessionInfo()` and `htan_snapshot_info()`;
the bug form asks for each.

**Open-ended discussion** (ideas, show and tell, analysis approaches) is
welcome in [GitHub Discussions](https://github.com/seandavi/HTAN/discussions).

Before asking, the [documentation site](https://seandavi.github.io/HTAN/)
has a getting-started guide and articles on the data model, the atlases and
an analysis workflow.
